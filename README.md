# Coca - Modern SaaS & Agency Landing Page

A premium, fully responsive landing page interface designed for digital agencies and SaaS products. This project demonstrates high-fidelity UI layout execution, pixel-perfect interactive components, and theme-switching capabilities.

## 🚀 Live Demo
[👉 Click here to view the live website](https://romarios144.github.io/coca/)

## 🛠️ Tech Stack & Tools
* **Core:** HTML5, CSS3 / SCSS (Structured BEM/Modules layout)
* **Framework/Library:** JavaScript (ES6+) / React
* **Environment & Build Tools:** Node.js (npm), Vite
* **Design Implementation:** Figma-to-Code pixel-perfect execution

## 📦 Key Features
* **Dark / Light Mode Toggle:** Seamless interactive theme switching implemented via modern state management.
* **Interactive Tabs & Accordions:** Dynamic content switching and FAQ accordion components built with clean JS logic.
* **Multi-slide Carousels/Sliders:** Fully responsive dynamic sliders for showcase materials.
* **Interactive UI Dashboards:** Clean rendering of sales reports, customer growth metrics, and custom vector charts.
* **Mobile-First Responsiveness:** Fully optimized layout across all device viewports (Desktop, Tablet, Mobile).

## ⚙️ Development Setup
To run this project locally:
1. Clone the repository
2. Run `npm install` to install dependencies
3. Run `npm run dev` to start the local development server
